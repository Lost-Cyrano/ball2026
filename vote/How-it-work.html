Coachella Élection
Comment voter pour votre Roi & Reine
← Retour au vote
📋 Étape 1 : Connexion
Entrez votre numéro à 4 chiffres (votre ID personnel) sur la page d'accueil. Seuls les élèves inscrits peuvent se connecter.
🗳️ Étape 2 : Voter
Une fois connecté, vous verrez deux colonnes :
  • 👑 Colonne de gauche : Les candidats pour le titre de Roi du Bal
  • 👸 Colonne de droite : Les candidates pour le titre de Reine du Bal
Cliquez sur "Voter pour lui / elle" sous le nom du candidat de votre choix.
Un vote est immédiat et ne peut pas être annulé.
⚠️ Étape 3 : Règles importantes
  • ❶ Chaque élève peut voter UNE SEULE FOIS pour un roi et UNE SEULE FOIS pour une reine.
  • ❷ Vous ne pouvez pas voter pour vous-même.
  • ❸ Une fois que vous avez voté dans une catégorie, les boutons de cette catégorie disparaissent.
  • ❹ Les votes sont comptés en temps réel et ne peut pas être annulé
🔍 Barre de recherche : Vous pouvez filtrer les candidats par nom, prénom ou ID dans les deux colonnes en même temps.
🎯 Besoin d'aide ?
Si vous n'arrivez pas à vous connecter ou si vous avez un problème :
  • • Vérifiez que vous utilisez le bon ID à 4 chiffres
  • • Assurez-vous d'être bien inscrit et de l'avoir validée à votre entrée
  • • Contactez l'organisation de la MDL
